## Risks

- Grafana LGTM's configuration through `*_EXTRA_ARGS` and a copy of Tempo's file is specific to 0.32.0 → `tests/0007-lgtm.sh` fails when the copy drifts from the image's file, when a port leaves the loopback, or when a signal stops flowing; an image upgrade regenerates the copy and re-runs it.
- Pyroscope's ring addresses were found by measurement (without them its ingest failed); another component of a later image may need the same → the data-flow part of `tests/0007-lgtm.sh`; reading a profile back is the one part not confirmed during planning (step 2's stop rule).
- A value of `*_EXTRA_ARGS` is split on spaces by the image's scripts (`read -ra`) → no value with a space.
- Compose recreates the shared services the first time `compose.apps.yml` lists a new application's network (their configuration changed) → one restart of Keycloak at the next `up.sh` or deployment after a new application's first registration, once per application; the registration itself only `docker network connect`s (no restart). The alternative (attach again after every `compose up`, nothing declared) avoids that restart but loses the attachments on a manual `docker compose up --force-recreate`; this plan keeps the declaration (REQ-5's "stay attached").
- `compose-file` emptying `compose.apps.yml` when `docker` answers nothing (a stub, a stopped daemon) → it rewrites only when `c4-infra`'s network answers, proven by step 4's `cksum` check; a network removed by hand while the file still names it → the next `compose-file` (before every `up`) drops it.

One of six throwaway starts failed reading `.erlang.cookie` (`eacces`) and wasn't reproduced → step 3's health check and AC-11.
- The hostile cases beyond the spec's list (`cap_add`, `pid: host`, devices, foreign volumes, `driver_opts` binds, `build` outside) are escapes of the same kind as REQ-9's last group → refused too; a legitimate need (an application wanting a capability) would be a new intent.
- `MP_UI_AUTH` holds a bcrypt hash in Mailpit's environment (`docker inspect`) → the same exposure as Caddy's environment today; a hash, not the password.
- Earlier tests changed by this plan (`tests/0003-demo-edge.sh`, the 0002 fixtures, three cleanups) → listed in Files; their assertions don't change.
- The stand-in tests take long (fresh host, images) → `tests/run.sh --all` only; the volume of the stand-in keeps the images between runs.
